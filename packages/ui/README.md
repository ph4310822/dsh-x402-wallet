# @danielng23/dsh-client-ui-x402

The browser half of the **dsh-x402-wallet** plugin: a Phantom-style wallet popup for the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) web GUI — balance hero, QR receive, USDC send, on-chain activity, wallet switching, and create/import — plus per-payment conversation cards for `x402_pay` calls.

Install the whole wallet in one step:

```sh
dsh plugin --profile web add @danielng23/dsh-x402-wallet
```

See the [main repository](https://github.com/ph4310822/dsh-x402-wallet) for the full product README.
