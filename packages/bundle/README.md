# @danielng23/dsh-x402-wallet

Installable [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) bundle: mounts the x402 payment host service and the wallet GUI into a `dsh web` profile as an opt-in patch layer.

```sh
dsh plugin --profile web add @danielng23/dsh-x402-wallet
```

Restart `dsh web` — the **x402 钱包** entry appears in the sidebar. See the [main repository](https://github.com/ph4310822/dsh-x402-wallet) for the full product README.
