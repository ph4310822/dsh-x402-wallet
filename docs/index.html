DSH X402 Wallet

DSH X402 Wallet

A visual x402 payment wallet for DeepSeek Harness. Your agent discovers paid APIs, estimates their cost, and pays-and-calls them over the x402 protocol — while a Phantom-style wallet popup keeps custody, QR receive, USDC send, and on-chain activity inside the DSH web GUI.

给 DeepSeek Harness 的可视化 x402 支付钱包。你的 Agent 通过 x402 协议发现付费 API、估算价格并支付调用—— Phantom 风格钱包弹窗在 DSH Web GUI 里提供多钱包托管、二维码收款、USDC 转出与链上活动。

Read the docs 阅读文档 
dsh plugin --profile web add @danielng23/dsh-x402-wallet

Restart dsh web — the x402 Wallet entry appears in the sidebar.

重启 dsh web——侧边栏出现 x402 钱包 入口。

What it is

它是什么

Your agent can pay for APIs

你的 Agent 可以为 API 付费

Four model tools — x402_discover, x402_estimate, x402_balance, x402_pay — discover x402-enabled APIs, probe their price without paying, and pay-and-call them with a spend cap and your approval.

四个模型工具——x402_discover、x402_estimate、x402_balance、x402_pay——发现支持 x402 的 API、不花钱探测价格，并在支出上限与你的审批下支付并调用。

Your wallet is a first-class GUI surface

你的钱包是一等的 GUI 表面

A Phantom-style popup manages several wallets (create / import / switch), shows the USDC balance, a QR receive screen, an on-chain transfer history, and a send form.

Phantom 风格弹窗管理多个钱包（创建/导入/切换）、展示 USDC 余额、二维码收款屏、链上转账历史与转出表单。

Keys never leave your machine

密钥绝不离开你的机器

Private keys live only in the Host credential store; the model, the logs, and the browser page never see them.

私钥只存放在 Host 凭据存储中；模型、日志与浏览器页面永远看不到它们。

How x402 payments work

x402 支付如何工作

The wallet speaks the x402 protocol natively with the exact (EIP-3009) scheme: the wallet signs a transfer authorization and the gateway settles on-chain — the wallet pays no gas. Every paid call enforces maxCostUsdc and asks for your approval first.

钱包原生使用 x402 协议的 exact（EIP-3009） scheme：钱包签署转账授权，网关在链上结算——钱包不付 gas。每笔付费调用强制执行 maxCostUsdc，并先请求你的审批。

Agent calls a paid API

Agent 调用付费 API

Model runs x402_pay → probe → cap → approval → EIP-3009 signature → gateway settles. Gas: none.

模型执行 x402_pay → 探测 → 上限 → 审批 → EIP-3009 签名 → 网关结算。Gas：无。

You move funds out of the wallet

你把资金转出钱包

Popup Send → plain on-chain ERC-20 transfer (viem, awaited receipt). Gas: yes (normal network gas).

弹窗 发送 → 普通链上 ERC-20 转账（viem，等待回执）。Gas：有（正常网络 gas）。

Install

安装

dsh plugin --profile web add @danielng23/dsh-x402-wallet

Published on the npm registry for any DSH installation. The wallet is opt-in — the shipped DSH web profile does not include it. Uninstall with dsh plugin --profile web remove @danielng23/dsh-x402-wallet.

已发布到 npm registry，适用于任意 DSH 安装。钱包是 opt-in 的——随产品发布的 DSH web profile 不包含它。卸载：dsh plugin --profile web remove @danielng23/dsh-x402-wallet。
